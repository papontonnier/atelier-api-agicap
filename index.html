Méthode de debug

      
    
        
  1. Rejouer hors application avec le curl généré. S'il passe, le problème est côté appelant (config, mapping, token).
    2. 
        
  2. Valider le token seul : GET /public/organizations/v1 doit répondre 200 et lister votre organisation.
    3. 
        
  3. Vérifier le périmètre : l'entityId figure-t-il dans /organizations/v1/{id}/entities ?
    4. 
        
  4. Lire le corps d'erreur : Agicap renvoie du application/problem+json (type, title, status, detail).
    5. 
        
  5. Envoyer un Request-Id (UUID) et le noter : c'est la référence à donner au support.
    6. 
        
  6. Réduire le lot : les endpoints Business Documents prennent un tableau, tester avec un seul document.
